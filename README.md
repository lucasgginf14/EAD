# Explotación de Almacenes de Datos

Repositorio que reúne diferentes trabajos y prácticas desarrollados en la asignatura **Explotación de Almacenes de Datos**, centrados en el análisis, consulta y tratamiento de información almacenada en sistemas orientados a la explotación de datos.

El objetivo principal es aplicar conceptos relacionados con bases de datos, consultas SQL y técnicas de análisis sobre grandes conjuntos de información.

## Contenido del repositorio

```text
EAD/
├── Práctica/
├── SQL/
└── TGRs/
```

### Práctica

Contiene el trabajo práctico principal de la asignatura, donde se aplican de forma conjunta los conceptos trabajados durante el curso.

### SQL

Incluye ejercicios y consultas realizadas mediante **SQL**, orientadas a la extracción, filtrado, agrupación y análisis de información almacenada en bases de datos.

Entre los conceptos trabajados se encuentran:

- Consultas sobre bases de datos.
- Filtrado y transformación de información.
- Agrupaciones y funciones de agregación.
- Relaciones entre diferentes conjuntos de datos.
- Obtención de información útil a partir de datos almacenados.

### TGRs

Recopila diferentes trabajos y ejercicios relacionados con los contenidos teóricos y prácticos de la asignatura.

## Objetivos

Los trabajos de este repositorio permiten poner en práctica conocimientos relacionados con:

- Explotación y análisis de datos.
- Bases de datos y SQL.
- Consulta y transformación de información.
- Análisis de conjuntos de datos.
- Resolución de problemas utilizando información almacenada.
- Trabajo con estructuras orientadas a la toma de decisiones.
